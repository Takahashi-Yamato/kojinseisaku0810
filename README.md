# もりのぼうけん

Unityで開発した2Dアクションゲームです。

## 概要

森を舞台にした2Dドット絵の横スクロールアクションゲーム「森の冒険」です。
プレイヤーは白いキャラクターを操作し、とげ(スパイク)などの障害物を避けながら、足場やジャンプ台を飛び移ってステージ奥にあるゴールの旗を目指します。

## 動作環境

- **エンジン**: Unity
- **対応プラットフォーム**: PC / スマートフォン

## 操作方法

### PC(キーボード操作)

| キー | 操作内容 |
| --- | --- |
| A | 左に移動 |
| D | 右に移動 |
| SPACE | ジャンプ |

### スマートフォン(タッチ操作)

画面下部に表示されるボタンをタップして操作します。

| ボタン | 位置 | 操作内容 |
| --- | --- | --- |
| ◀ ボタン | 画面左下 | 左に移動 |
| ▶ ボタン | 画面左下 | 右に移動 |
| 丸ボタン | 画面右下 | ジャンプ |

## ゲームの流れ

1. とげ(スパイク)や段差などの障害物を避けながら進む
2. 足場やジャンプ台を飛び移ってステージを進む
3. ステージの先にある旗(ゴール)に到達すればクリア
